# entregafinal / Radiohead Álbum In Rainbows

## Mi idea principal consiste en crear una página web inspirada en la estética del álbum In Rainbows de Radiohead, con la canción Weird Fishes/Arpeggi de fondo. La idea consiste en que alrededor de la página haya diferentes peces con estética neón que, al tocarlos, te lleven directamente a la letra de la canción.
