# entregafinal / Radiohead Álbum In Rainbows

## Mi idea principal consiste en crear una página web alrededor de la estética del álbum In Rainbows de Radiohead, donde de fondo suene la canción Weird Fishes/Arpeggi. La idea consiste en que alrededor de la página haya diferentes peces con estética neón que, al tocarlos, te lleven directamente a la letra de la canción.
