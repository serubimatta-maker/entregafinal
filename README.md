# entrega final / Radiohead Álbum In Rainbows

## Mi idea principal consiste en crear una página web inspirada en la estética del álbum In Rainbows de Radiohead, con la canción Weird Fishes/Arpeggi de fondo. La idea consiste en que alrededor de la página haya diferentes peces con estética neón que, al tocarlos, te lleven directamente a la letra de la canción.

### El fondo y música
El fondo va a consistir en un video stock sacado de YouTube, el cual se exportará al formato mp4. En ese momento se pondrá en assets para ponerlo en un html como un video normal y, desde css, ajustarlo para que quede como un fondo. La música de fondo se logrará descargando la canción en mp3 y poniéndola dentro del html para que se reproduzca instantáneamente.

### Los peces
Para este caso se tienen 2 teorías diferentes de cómo podría funcionar. 
#### Formato gif
En el caso de que se llegue a crear una ilustración en Illustrator, se pasará a Adobe After Effects para que de esta manera pueda ser un gif animado a 24 fps.
#### Formato SVG
A diferencia del anterior, este utilizará una librería, ya sea de css o javascript, para poder animar la figura creada desde Illustrator, para que de esta manera tenga un movimiento más repentino.
